I've always kept my shell history, even when changing computer. It's usually the first thing I
transfer. I've had this idea of storing my shell history in the cloud for years, I even started
building a solution. I chose Rust because I wanted it to be fast, and Rust is fun to write.

I remember I struggled a lot with the HTTP API. This was a few years ago, and there were no good
Rust HTTP API frameworks at the time. Anyway, I never finished it, but the idea never left me.

Then I discovered [Atuin](https://atuin.sh/), a shell history manager that does exactly what I
wanted to do, but 100 times better. And then I discovered that you can self host it! So I did.
It took me about 30 minutes to set it up, and now I have all my shell history in my own cloud.
